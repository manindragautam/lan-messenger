About LAN Messenger 🦕

Architecture Highlights

  • Deno Desktop Native: Runs natively with deno desktop via OS webview bindings, zero Node.js and zero Bun.
  • UDP Peer Discovery: Broadcasts heartbeats on UDP port 45450 for zero-configuration instant local discovery.
  • Direct P2P LAN Delivery: Messages and file transfers route directly between peers via local HTTP & WebSockets.
  • Subnet Fallback: Includes active subnet scanner and direct IP connect for environments with Wi-Fi AP isolation.
  • High-Speed LAN Transfers: Share images, audio voice notes, and documents with zero cloud servers or third-party tracking.
